# Future Creator SDK

Approved creators receive a separate SDK and sample Construct 3 project—not the core `.c3p`, event sheets, server source, credentials, or write APIs. A capability token binds player, expansion, session, endpoints, permissions, expiry, and nonce. Public APIs expose only approved display/appearance metadata, score/completion submission, reward request, and return-to-game behavior.

Packages are checksum-verified, signed, versioned, reviewed, revocable, and never execute arbitrary code on the game server. Creator results are claims that the authoritative Mariposa service independently verifies.
